## 🛠️ 单篇 Notebook 工程质量硬性标准
1. **全量创新点穷尽**：系统通读全文，不遗漏任何工程机制与理论贡献；
2. **纯净自包含代码**：每个子模块自带输入 Mock 张量与 `assert` 维度检查，无隐式外部依赖；
3. **消融实验证据链**：绑定原论文消融表格数据，量化模块增益；
4. **顶刊/顶会改进背书**：只引用 CCF-A 级顶会顶刊论文（如 NeurIPS/ICLR/TPAMI）的后续改进方案；
5. **自我验收机制**：生成完毕强制执行 Self-Verification Checklist。
